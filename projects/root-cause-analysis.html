Project 05 of 06 / Osler Diagnostics, 2025

Root cause analysis: 94% reject rate to near zero

Precision sealing interface assemblies for medical diagnostics had a 94% component reject rate. I found the root cause with tolerance stack-up analysis and fault finding, and the reject rate came down to near zero.

The problem

The components in precision sealing interface assemblies (used in medical diagnostics) had a 94% reject rate.

What I did

I used tolerance stack-up analysis and fault finding to find the root cause. I then put corrective design and process changes in place and verified them with follow on testing.

Validation work

I designed and built the validation setups myself. I ran pressure, leak and functional tests, recorded the results and wrote formal test reports against defined acceptance criteria.

Result

The reject rate came down to near zero and commissioning time fell by 20%.
